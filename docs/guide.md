## 상수 변경 및 테스트 가이드

### 1. 물리 상수 변경 확인

#### 1.1. 헬리콥터 이동 테스트
- 최대 속도 (MAX_SPEED) 확인
  1. 좌/우 키를 길게 눌러 최대 속도 도달 시간 측정
  2. 최대 속도에서 정지까지의 감속 시간 확인
  3. 예상 동작: 3초 내 최대 속도 도달, 2초 내 완전 정지

#### 1.2. 회전 시스템 테스트
- 최대 회전 각도 (MAX_ROTATION) 확인
  1. 좌/우 키를 눌러 최대 기울기 확인
  2. 키 해제 시 수평 복귀 속도 확인
  3. 예상 동작: 45도 최대 기울기, 0.5초 내 수평 복귀

### 2. 프로펠러 상수 확인

#### 2.1. 회전 속도 테스트
- 프로펠러 회전 속도 (PROPELLER_SPEED) 확인
  1. 정지 상태에서 프로펠러 회전 속도 관찰
  2. 이동 중 프로펠러 회전 속도 변화 확인
  3. 예상 동작: 초당 7.5회전 (15π rad/s)

#### 2.2. 프로펠러 크기 테스트
- 프로펠러 크기 비율 (PROPELLER_SCALE) 확인
  1. 헬리콥터 본체 대비 프로펠러 크기 확인
  2. 회전 시 프로펠러 가시성 확인
  3. 예상 동작: 본체 너비의 1.2배

### 3. 연기 효과 상수 확인

#### 3.1. 파티클 생성 테스트
- 파티클 생성 속도 (SMOKE_SPAWN_RATE) 확인
  1. 정지 상태에서 연기 발생량 확인
  2. 이동 중 연기 발생량 변화 확인
  3. 예상 동작: 초당 20개 파티클 생성

#### 3.2. 파티클 수명 테스트
- 파티클 지속 시간 (SMOKE_LIFETIME) 확인
  1. 개별 연기 파티클의 소멸 시간 측정
  2. 파티클 투명도 감소 속도 확인
  3. 예상 동작: 1.5초 수명, 선형적 투명도 감소

### 4. 성능 모니터링

#### 4.1. FPS 확인
- 프레임 속도 모니터링
  1. 정지 상태에서 FPS 확인
  2. 고속 이동 시 FPS 확인
  3. 목표: 안정적 60 FPS 유지

#### 4.2. 메모리 사용량
- 파티클 시스템 메모리 영향
  1. 연기 효과 최대 상태에서 메모리 사용량 확인
  2. 장시간 실행 시 메모리 누수 여부 확인
  3. 목표: 메모리 사용량 50MB 이하 유지

### 5. 버그 체크리스트

- [ ] 물리 상수 변경 후 경계 충돌 정상 작동
- [ ] 프로펠러 회전 시 시각적 글리치 없음
- [ ] 연기 파티클 생성/소멸 시 프레임 드롭 없음
- [ ] 빠른 방향 전환 시 회전 각도 제한 정상 작동
- [ ] 연기 효과가 게임 성능에 과도한 영향 없음
